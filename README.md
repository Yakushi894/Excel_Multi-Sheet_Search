# Excel_Multi-Sheet_Search

Search across many Excel files (including subfolders) by a product code, and instantly find the matching row — price-tag code, product name, prices — plus which file it was in.

フォルダ＋子フォルダに散らばった多数の Excel を、品番コードで横断検索する単体 PHP です。
外部ライブラリ不要、Docker ですぐ動きます。日本語フォルダ名・日本語ファイル名対応。

**配布イメージ（Docker Hub）**: https://hub.docker.com/r/yuichi894/excel-multi-sheet-search

```bash
docker pull yuichi894/excel-multi-sheet-search:1.0
```

## できること

- 品番コード（8桁の数字、例 `12345678`）を入力して検索
- スマホでは結果が1件ごとのカード（BOX）表示になり、全項目を表示（PCでは表形式）
- 結果に商品画像を表示可能（画像URLテンプレート設定時）
- フッターの About から、バージョンと配布先（GitHub / Docker Hub）へのリンクを表示
- Dockerで渡したフォルダ（例：`/Work`）＋その全子フォルダの `.xlsx` / `.xlsm` を横断検索
- ヒットした行のプライスタグ品番（例 `999-0001`）、商品名、売価・基準価格・原価などと
  Excel名（ダウンロードリンク付き）を表示
- **索引（インデックス）を `/Index` に保持**し、2回目以降は高速。
  Excelの追加・更新・削除は変更分だけ自動で読み直し
- 逆引き（タグ品番から）、部分一致、商品名検索、ファイル名一致の表示も対応

想定しているシートの形（見出し行で列を自動判定します）：

| グループ番号 | 商品名 | プライス品番・タグ品番(連番) | 発注数 | 基準価格 | 推定原価 | 推定売価 | メーカー品番 | スペック |
|---|---|---|---|---|---|---|---|---|
| 13 | サンプル商品A | 999-0001 | 1 | | | 79,000 | 12345678 | サンプル |

※見出しのキーワード（メーカー品番／商品品番／プライス品番／タグ品番／価格 など）は
`index.php` 内の判定箇所で自社フォーマットに合わせて編集できます。

結果の Excel名欄は「何行目か」を先頭に表示し、フォルダ場所とシート（何枚目か）は折りたたみで表示します。

## 設定（画面下部「設定」から変更、`settings.json` に保存）

| 項目 | 内容 |
|---|---|
| ノード表示 | 背景アニメーション自体を描画しない設定（設定欄で切替） |
| ファイルの時期表示 | 商品名の下に、ファイルの更新日時から「2025年10月頃のファイル（約2ヶ月前）」のように時期を表示（ON/OFF） |
| 画像URLテンプレート | 商品画像のURL雛形（`{code}` `{price}` `{name}` `{group}` を置換）。設定時は結果の右端にサムネイル表示し、クリックでポップアップ拡大（外側クリックで閉じる）。未指定なら画像欄なし、画像が無い行は「ありません」表示 |
| 表示レイアウト | 結果表の列順・表示名を指定。設定内のポップアップ編集画面（並び替え・追加・削除）でも、JSON直接入力でも可（最大15列）。空欄＝標準表示 |
| 背景アニメーション | ON（標準配色）/ OFF / ライトテーマ / ブラックテーマ（画面も暗色） |
| ノード数 | 少ない（44）/ 中（88）/ 多い（160） |
| 検索フォルダ | 初期値 `/Work`。日本語フォルダ可 |
| 読み込むシート | **何枚目か（初期値＝1枚目）** ／ シート名の一部 ／ 全シート。シート名がファイルごとに変わる場合に対応 |
| 検索列（A〜Z） | 例：`N` ／ `A-Z` ／ `B,N,P`。空欄＝見出し行から品番列を自動判定 |
| 表示列（最大10） | 例：`F,N,C,L,O`。結果表に出す列を列文字で指定。空欄＝標準表示。11個以上は先頭10個＋警告 |

### 検索の仕様メモ

- セル内に **`12345678+12345679`** のように複数品番が入っている場合も、
  数字の塊ごとに切り分けて照合するので、どちらの品番でもヒットします
- **結合セル**は左上の値を結合範囲全体に展開してから検索・表示します
  （横結合の見出し、縦結合で複数行にまたがる値も拾います）
- 品番が数値セルで先頭の0が落ちている場合も、8桁にそろえて照合します
- 全角数字・全角の列指定も半角に直して処理します

## Docker での起動

```bash
docker compose up -d --build
# ブラウザで http://<ホストのアドレス>:8080/ を開く
```

`docker-compose.yml` の volumes を自分の環境に書き換えてください：

```yaml
volumes:
  - /path/to/Excelフォルダ:/Work:ro   # Excelの親フォルダ（読み取り専用でOK、日本語可）
  - ./index:/Index                    # 索引と設定の保存先（書き込み必須）
```

- `/Index` をボリュームとして残しておけば、コンテナを作り直しても索引と設定が残ります

「索引の保存先」が `/var/www/html` 等と表示される場合は、`/Index` に書けていないためコンテナ内に保存されており、更新・リセットで消えます（画面にも警告が出ます）。
原因はたいてい、Index フォルダの ACL に書き込み許可のエントリが無いことです。フォルダの所有者が「33」（www-data）と表示されるのは正常で、NAS に存在しない番号の UID でも動作します（所有者の問題ではありません）。
対処：File Station で Index フォルダ → プロパティ → 「権限」タブ → 作成で `everyone` に読み取り＋書き込みを許可し、適用先を「このフォルダ、子フォルダ、ファイル」にします。その後ページを再読み込みすると保存先が `/Index` に切り替わります。

設定は `settings.json` に保存され、バージョンを跨いでも項目が保持されます（保存時に `settings.json.bak` へ前回分を残します）。

## トラブルシューティング

**「検索フォルダが見つからないか、読み取り権限がありません：/Work」と出る場合**

1. まずボリューム指定で対象フォルダが `/Work` にマウントされているか確認してください。
2. **対象フォルダ自体に閲覧権限を付けるのが確実です（推奨）。**
   コンテナの実行ユーザー（既定では www-data）がフォルダを読める必要があります。
   - Synology の場合：File Station で対象フォルダの権限を開き、「everyone」に
     読み取りを付けてください。詳細設定では次の3つにチェックが要ります：
     「フォルダの一覧表示 / データの読取り」「フォルダ間の移動 / 実行ファイル」
     「属性の読み取り」。サブフォルダへも継承させてください。
     （Synology の共有フォルダは ACL 管理で、権限表示が 0000 になることがあります。
     この場合 UID を合わせても読めないことがあり、フォルダ側の権限付与が確実です）
   - 通常の Linux フォルダの場合：所有者以外にも読み取り＋実行（r-x）を付けてください。
3. フォルダの権限を広げたくない場合は、コンテナの環境変数 `PUID` / `PGID` に
   フォルダ所有者のUID/GIDを指定する方法もあります
   （自分のIDはホストに SSH して `id` コマンドで確認できます。Synology の例：1024 / 100）。
   compose では `environment` に `PUID: "1024"` のように書きます（サンプル同梱済み）。
   環境変数を変えたら、コンテナの再起動ではなく**作り直し**が必要です。
   ただし ACL 管理フォルダでは PUID を合わせても読めない場合があり、その場合は 2. が必要です。
4. 警告画面内の「権限チェック」に、PUID/PGID がコンテナへ届いているか、
   実行ユーザーのUID、フォルダの読み取り・索引フォルダの書き込みテスト結果が
   OK/NG で表示されます。切り分けに使ってください。

## Dockerを使わない場合

`index.php` を Excel の親フォルダに置けば、そのフォルダが検索対象になり、
索引と設定も同じ場所に作られます（PHP 7.4+、拡張 dom / libxml / zlib を使用。
zip 拡張があると高速ですが、無くても内蔵リーダーで読めます）。

## 注意

- 旧形式 `.xls` は対象外です（Excelで `.xlsx` として保存し直してください）
- Excelを開いたときの一時ファイル（`~$...`）は自動で除外されます
- 検索ページ自体に認証はありません。LAN内での利用を前提にしています
  （外部公開する場合はリバースプロキシ側で認証をかけてください）
